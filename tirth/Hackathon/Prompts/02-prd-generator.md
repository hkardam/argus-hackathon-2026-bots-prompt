requirements.md

Do not create database schemas.

Do not generate APIs.

Focus only on WHAT needs to be built.

Problem Overview

Business Objective

Expected Outcome

# User Personas

- Name
- Goals
- Pain Points
- Technical Expertise

# User Stories

Format:

As a <user>

I want to <goal>

So that <benefit>

Generate ALL relevant stories.

# Functional Requirements

Feature Name

Description

Acceptance Criteria

Priority

(Must Have / Should Have / Nice To Have)

Performance

Security

Scalability

Availability

Usability

Accessibility

# User Flows

Step-by-step journeys.

Happy path.

Failure path.

Alternative path.

# Business Rules

# Assumptions

Product Risks
